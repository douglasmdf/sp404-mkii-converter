# SP-404 MKII Converter — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App de desktop (macOS + Windows) que converte em lote sample packs para WAV 16 bits / 48 kHz pronto para importar na Roland SP-404 MKII.

**Architecture:** Workspace Cargo com três crates: `core` (biblioteca Rust com toda a lógica — scan → Plan → runner), `cli` (binário `sp404` sobre o core) e `app/src-tauri` (app Tauri 2 cuja interface TypeScript chama comandos que delegam ao core). O `Plan` separa decidir de fazer: Dry Run mostra o Plan, Converter o executa, Desfazer usa o manifesto gravado pelo runner.

**Tech Stack:** Rust (edition 2021), symphonia 0.5.5 (decode), rubato 0.15.0 (resample), hound 3.5 (WAV), rayon (paralelismo), deunicode (ASCII), fs4 0.13.1 (espaço livre), clap 4 (CLI), Tauri 2 + plugin-dialog, TypeScript + Vite (sem framework de UI).

**Spec:** `docs/superpowers/specs/2026-10-14-sp404-converter-design.md`

## Global Constraints

- Saída de áudio: WAV PCM, **16 bits, 48 000 Hz**, contendo **apenas** os chunks `fmt ` (16 bytes, formato 1 = PCM) e `data`.
- Mono continua mono, estéreo continua estéreo; >2 canais → downmix estéreo (padrão ligado) ou falha `TooManyChannels`.
- Dither TPDF ao quantizar para 16 bits, **exceto** quando a origem já é PCM inteiro ≤16 bits a 48 kHz com ≤2 canais (aí a conversão é bit a bit idêntica).
- Picos acima de 0 dBFS (|x| > 1.0) são limitados e geram aviso `Clipped`; arquivos > 16 min geram aviso `TooLong`.
- Defaults: sanitizar nomes **ligado**; sanitizar pastas **desligado**; tamanho máximo **sem limite**; achatar pastas **desligado**; downmix **ligado**; destino **perguntar a cada vez**; workers = núcleos lógicos (máx. 8); log JSON **desligado**.
- Estrutura de subpastas preservada por padrão (a SP-404 MKII navega subpastas — confirmado pelo usuário).
- Versões fixadas com API verificada no código-fonte: `symphonia = "=0.5.5"`, `rubato = "=0.15.0"`, `fs4 = "=0.13.1"`. **Não** atualizar para symphonia 0.6 / rubato ≥1.0 (APIs diferentes).
- Sem FFmpeg no app distribuído. FFmpeg é usado **só** em desenvolvimento para gerar fixtures de teste (Task 4), que ficam commitadas.
- Instaladores: `.dmg` (macOS arm64 + x64) e `.exe` NSIS (Windows x64). **Nenhum `.msi`.**
- Interface em português e inglês, escolhida pelo idioma do sistema.
- `SP404_DATA_DIR` (variável de ambiente) sobrescreve a pasta de dados do app — usada pelos testes para não tocar nas configurações reais.
- A partir da Task 10, `cargo test --workspace` exige `app/dist` existir: rode `npm run build --prefix app` antes.
- Toda mensagem de commit termina com a linha `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Nomes que colidem em sistemas de arquivos que ignoram maiúsculas** (APFS, NTFS, exFAT do cartão SD): `Snare.mp3`, `snare.aif` e `snare.wav` na mesma pasta viram todos `snare.wav` — os três devem sobreviver como `Snare.wav`, `snare_2.wav`, `snare_3.wav`. Testes: Task 2 (`resolver_is_case_insensitive`) e Task 3 (`same_stem_different_extensions_all_survive`).
2. **Pasta de saída igual ou dentro do pack de origem** (no modo "perguntar", o usuário escolhe a pasta-mãe do pack): o app deve recusar, nunca escrever por cima dos originais. Teste: Task 3 (`output_inside_source_is_rejected`).
3. **Lixo de sistema em packs baixados** (`._kick.wav` AppleDouble, `.DS_Store`, `__MACOSX/`, `Thumbs.db`, `desktop.ini`): não deve aparecer como áudio quebrado nem ser copiado. Teste: Task 3 (`system_junk_is_ignored`).
4. **Áudio vazio ou muito curto** (one-shots de poucas amostras, menores que o bloco do resampler; WAV com 0 frames): deve gerar WAV válido com a duração certa, sem travar. Testes: Task 4 (`zero_length_wav_decodes_to_no_frames`), Task 5 (`resample_short_and_empty_inputs`), Task 6 (`zero_length_file_converts_to_empty_wav`).
5. **Arquivo que já está em 16 bits / 48 kHz**: as amostras devem sair bit a bit idênticas (sem ruído de dither). Testes: Task 5 (`process_passthrough_is_bit_exact`) e Task 6 (`already_compliant_file_is_bit_identical`).

use std::path::{Path, PathBuf};

#[derive(Debug, thiserror::Error)]
pub enum CoreError {
    #[error("I/O error at {path}: {source}")]
    Io {
        path: PathBuf,
        #[source]
        source: std::io::Error,
    },
    #[error("not a folder: {0}")]
    NotADirectory(PathBuf),
    #[error("output folder {dest} is the same as or inside the source pack {source_dir}")]
    OutputInsideSource { dest: PathBuf, source_dir: PathBuf },
    #[error("no output folder chosen")]
    NoOutputDir,
    #[error("unsupported audio format")]
    UnsupportedFormat,
    #[error("could not decode audio: {0}")]
    Decode(String),
    #[error("file has {0} channels and multichannel downmix is off")]
    TooManyChannels(usize),
    #[error("resampling failed: {0}")]
    Resample(String),
    #[error("could not write WAV: {0}")]
    Encode(String),
    #[error("not enough disk space: need {needed} bytes, {available} available")]
    InsufficientSpace { needed: u64, available: u64 },
    #[error("internal error: {0}")]
    Internal(String),
}

pub type Result<T> = std::result::Result<T, CoreError>;

pub(crate) fn io_err(path: &Path) -> impl FnOnce(std::io::Error) -> CoreError + '_ {
    move |source| CoreError::Io {
        path: path.to_path_buf(),
        source,
    }
}

//! User settings, persisted as JSON in the OS config folder.

use std::ffi::OsString;
use std::path::{Path, PathBuf};

use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub enum SaveMode {
    Ask,
    Fixed,
    NextToSource,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(default, rename_all = "camelCase")]
pub struct Settings {
    pub sanitize_filenames: bool,
    pub sanitize_folder_names: bool,
    pub max_filename_length: Option<usize>,
    pub flatten_folders: bool,
    pub downmix_multichannel: bool,
    pub save_mode: SaveMode,
    pub fixed_directory: Option<PathBuf>,
    pub workers: usize,
    pub write_json_log: bool,
}

impl Default for Settings {
    fn default() -> Self {
        Settings {
            sanitize_filenames: true,
            sanitize_folder_names: false,
            max_filename_length: None,
            flatten_folders: false,
            downmix_multichannel: true,
            save_mode: SaveMode::Ask,
            fixed_directory: None,
            workers: default_workers(),
            write_json_log: false,
        }
    }
}

pub fn default_workers() -> usize {
    std::thread::available_parallelism()
        .map(|n| n.get())
        .unwrap_or(4)
        .min(8)
}

impl Settings {
    /// Reads settings; a missing or unreadable file yields defaults.
    pub fn load_from(path: &Path) -> Settings {
        match std::fs::read_to_string(path) {
            Ok(text) => serde_json::from_str(&text).unwrap_or_default(),
            Err(_) => Settings::default(),
        }
    }

    pub fn save_to(&self, path: &Path) -> std::io::Result<()> {
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        let json = serde_json::to_string_pretty(self).expect("settings always serialize");
        std::fs::write(path, json)
    }

    pub fn load() -> Settings {
        Settings::load_from(&settings_path())
    }

    pub fn save(&self) -> std::io::Result<()> {
        self.save_to(&settings_path())
    }
}

/// Folder for settings and the undo manifest. `SP404_DATA_DIR` overrides it (used by tests).
pub fn app_data_dir() -> PathBuf {
    data_dir_from(std::env::var_os("SP404_DATA_DIR"))
}

pub fn data_dir_from(env_override: Option<OsString>) -> PathBuf {
    match env_override {
        Some(dir) => PathBuf::from(dir),
        None => dirs::config_dir()
            .unwrap_or_else(std::env::temp_dir)
            .join("sp404-converter"),
    }
}

pub fn settings_path() -> PathBuf {
    app_data_dir().join("settings.json")
}
```

```rust
//! Pure functions that turn source names into SP-404-safe output names.

use std::collections::HashSet;
use std::path::Path;

use deunicode::deunicode;

const WINDOWS_RESERVED: &[&str] = &[
    "CON", "PRN", "AUX", "NUL", "COM1", "COM2", "COM3", "COM4", "COM5", "COM6", "COM7", "COM8",
    "COM9", "LPT1", "LPT2", "LPT3", "LPT4", "LPT5", "LPT6", "LPT7", "LPT8", "LPT9",
];

/// Sanitizes one path component (a file stem or a folder name): ASCII letters, digits,
/// `-` and `_` only, no repeated or edge underscores, never empty, never a Windows device name.
pub fn sanitize_component(name: &str) -> String {
    let ascii = deunicode(name);
    let mut out = String::with_capacity(ascii.len());
    for ch in ascii.chars() {
        let mapped = if ch.is_ascii_alphanumeric() || ch == '-' { ch } else { '_' };
        if mapped == '_' && out.ends_with('_') {
            continue;
        }
        out.push(mapped);
    }
    let trimmed = out.trim_matches('_');
    let mut result = if trimmed.is_empty() {
        String::from("untitled")
    } else {
        trimmed.to_string()
    };
    if WINDOWS_RESERVED.iter().any(|r| r.eq_ignore_ascii_case(&result)) {
        result.push('_');
    }
    result
}

pub fn truncate_chars(s: &str, max: usize) -> String {
    s.chars().take(max).collect()
}

/// `["Breaks", "Funk"]` + `"kick"` → `"Breaks_Funk_kick"`.
pub fn flatten_stem<S: AsRef<str>>(dirs: &[S], stem: &str) -> String {
    let mut parts: Vec<&str> = dirs.iter().map(|d| d.as_ref()).collect();
    parts.push(stem);
    parts.join("_")
}

/// Hands out unique file names per output folder. Comparison ignores case because the
/// SD card (exFAT), APFS and NTFS all do.
#[derive(Debug, Default)]
pub struct CollisionResolver {
    taken: HashSet<String>,
}

impl CollisionResolver {
    pub fn new() -> Self {
        Self::default()
    }

    pub fn claim(&mut self, dir: &Path, stem: &str, ext: &str, max_len: Option<usize>) -> String {
        let mut n = 1usize;
        loop {
            let suffix = if n == 1 { String::new() } else { format!("_{n}") };
            let stem_part = match max_len {
                Some(max) => truncate_chars(stem, max.saturating_sub(suffix.chars().count())),
                None => stem.to_string(),
            };
            let file_name = if ext.is_empty() {
                format!("{stem_part}{suffix}")
            } else {
                format!("{stem_part}{suffix}.{ext}")
            };
            let key = dir.join(&file_name).to_string_lossy().to_lowercase();
            if self.taken.insert(key) {
                return file_name;
            }
            n += 1;
        }
    }
}

//! Walks pack folders and builds a `Plan`: every source file, where it goes and how.
//! Nothing here writes to disk.

use std::collections::HashSet;
use std::fs;
use std::path::{Path, PathBuf};

use serde::{Deserialize, Serialize};

use crate::config::{SaveMode, Settings};
use crate::error::{io_err, CoreError, Result};
use crate::naming::{flatten_stem, sanitize_component, CollisionResolver};

pub const CONVERTIBLE_EXTENSIONS: &[&str] = &[
    "wav", "wave", "aif", "aiff", "aifc", "flac", "mp3", "m4a", "aac", "ogg", "oga", "caf",
];
pub const UNSUPPORTED_AUDIO_EXTENSIONS: &[&str] =
    &["opus", "wma", "ape", "wv", "mpc", "ra", "amr", "dsf", "dff"];
const IGNORED_NAMES: &[&str] = &["__MACOSX", "Thumbs.db", "desktop.ini"];

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub enum JobKind {
    Convert,
    Copy,
    Unsupported,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct Job {
    pub source: PathBuf,
    pub dest: PathBuf,
    pub kind: JobKind,
    pub already_exists: bool,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct PackPlan {
    pub name: String,
    pub source_root: PathBuf,
    pub dest_root: PathBuf,
    pub jobs: Vec<Job>,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct Plan {
    pub packs: Vec<PackPlan>,
}

impl Plan {
    pub fn jobs(&self) -> impl Iterator<Item = &Job> + '_ {
        self.packs.iter().flat_map(|p| p.jobs.iter())
    }
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct PackSummary {
    pub name: String,
    pub path: PathBuf,
    pub audio_files: usize,
    pub other_files: usize,
    pub unsupported_files: usize,
}

pub fn is_ignored(name: &str) -> bool {
    name.starts_with('.') || IGNORED_NAMES.iter().any(|n| n.eq_ignore_ascii_case(name))
}

pub fn classify(path: &Path) -> JobKind {
    let ext = path
        .extension()
        .and_then(|e| e.to_str())
        .map(|e| e.to_ascii_lowercase())
        .unwrap_or_default();
    if CONVERTIBLE_EXTENSIONS.contains(&ext.as_str()) {
        JobKind::Convert
    } else if UNSUPPORTED_AUDIO_EXTENSIONS.contains(&ext.as_str()) {
        JobKind::Unsupported
    } else {
        JobKind::Copy
    }
}

pub fn inspect_pack(dir: &Path) -> Result<PackSummary> {
    if !dir.is_dir() {
        return Err(CoreError::NotADirectory(dir.to_path_buf()));
    }
    let mut summary = PackSummary {
        name: dir_name(dir),
        path: dir.to_path_buf(),
        audio_files: 0,
        other_files: 0,
        unsupported_files: 0,
    };
    for rel in collect_files(dir)? {
        match classify(&rel) {
            JobKind::Convert => summary.audio_files += 1,
            JobKind::Copy => summary.other_files += 1,
            JobKind::Unsupported => summary.unsupported_files += 1,
        }
    }
    Ok(summary)
}

pub fn build_plan(pack_dirs: &[PathBuf], output_dir: Option<&Path>, settings: &Settings) -> Result<Plan> {
    let mut used_roots = HashSet::new();
    let mut packs = Vec::with_capacity(pack_dirs.len());
    for source_root in pack_dirs {
        if !source_root.is_dir() {
            return Err(CoreError::NotADirectory(source_root.clone()));
        }
        let base_name = pack_name(source_root, settings);
        let mut n = 1usize;
        let (name, dest_root) = loop {
            let name = if n == 1 { base_name.clone() } else { format!("{base_name}_{n}") };
            let dest_root = pack_dest_root(source_root, &name, output_dir, settings)?;
            if used_roots.insert(dest_root.to_string_lossy().to_lowercase()) {
                break (name, dest_root);
            }
            n += 1;
        };
        ensure_outside(&dest_root, source_root)?;
        packs.push(plan_pack(source_root, name, dest_root, settings)?);
    }
    Ok(Plan { packs })
}

fn plan_pack(source_root: &Path, name: String, dest_root: PathBuf, settings: &Settings) -> Result<PackPlan> {
    let mut resolver = CollisionResolver::new();
    let mut jobs = Vec::new();
    for rel in collect_files(source_root)? {
        let kind = classify(&rel);
        let dirs: Vec<String> = rel
            .parent()
            .map(|p| p.iter().map(|c| c.to_string_lossy().into_owned()).collect())
            .unwrap_or_default();
        let stem = rel.file_stem().map(|s| s.to_string_lossy().into_owned()).unwrap_or_default();
        let original_ext = rel.extension().map(|e| e.to_string_lossy().into_owned()).unwrap_or_default();

        let rel_dir: PathBuf = if settings.flatten_folders {
            PathBuf::new()
        } else {
            dirs.iter()
                .map(|d| if settings.sanitize_folder_names { sanitize_component(d) } else { d.clone() })
                .collect()
        };
        let stem = if settings.flatten_folders { flatten_stem(&dirs, &stem) } else { stem };
        let (stem, ext, max_len) = match kind {
            JobKind::Convert => {
                let stem = if settings.sanitize_filenames { sanitize_component(&stem) } else { stem };
                (stem, String::from("wav"), settings.max_filename_length)
            }
            JobKind::Copy | JobKind::Unsupported => (stem, original_ext, None),
        };
        let file_name = resolver.claim(&rel_dir, &stem, &ext, max_len);
        let dest = dest_root.join(&rel_dir).join(&file_name);
        let already_exists = dest.exists();
        jobs.push(Job { source: source_root.join(&rel), dest, kind, already_exists });
    }
    Ok(PackPlan { name, source_root: source_root.to_path_buf(), dest_root, jobs })
}

fn dir_name(dir: &Path) -> String {
    dir.file_name()
        .map(|n| n.to_string_lossy().into_owned())
        .unwrap_or_else(|| String::from("pack"))
}

fn pack_name(source_root: &Path, settings: &Settings) -> String {
    let raw = dir_name(source_root);
    if settings.sanitize_folder_names { sanitize_component(&raw) } else { raw }
}

fn pack_dest_root(source_root: &Path, name: &str, output_dir: Option<&Path>, settings: &Settings) -> Result<PathBuf> {
    match settings.save_mode {
        SaveMode::Ask => Ok(output_dir.ok_or(CoreError::NoOutputDir)?.join(name)),
        SaveMode::Fixed => Ok(settings
            .fixed_directory
            .as_deref()
            .ok_or(CoreError::NoOutputDir)?
            .join(name)),
        SaveMode::NextToSource => {
            let parent = source_root.parent().ok_or(CoreError::NoOutputDir)?;
            Ok(parent.join(format!("{name} [SP-404]")))
        }
    }
}

fn ensure_outside(dest_root: &Path, source_root: &Path) -> Result<()> {
    if resolve_path(dest_root).starts_with(resolve_path(source_root)) {
        return Err(CoreError::OutputInsideSource {
            dest: dest_root.to_path_buf(),
            source_dir: source_root.to_path_buf(),
        });
    }
    Ok(())
}

/// Absolute path with symlinks resolved for the part that exists (so `/var` and
/// `/private/var` on macOS compare equal), keeping the not-yet-created tail as is.
fn resolve_path(path: &Path) -> PathBuf {
    let absolute = std::path::absolute(path).unwrap_or_else(|_| path.to_path_buf());
    let mut existing = absolute.as_path();
    let mut tail = Vec::new();
    while !existing.exists() {
        match (existing.parent(), existing.file_name()) {
            (Some(parent), Some(name)) => {
                tail.push(name.to_os_string());
                existing = parent;
            }
            _ => break,
        }
    }
    let mut resolved = existing.canonicalize().unwrap_or_else(|_| existing.to_path_buf());
    for name in tail.iter().rev() {
        resolved.push(name);
    }
    resolved
}

/// Relative paths of every regular file under `root`, sorted, skipping system junk.
/// Symlinks are not followed.
fn collect_files(root: &Path) -> Result<Vec<PathBuf>> {
    let mut out = Vec::new();
    walk(root, Path::new(""), &mut out)?;
    out.sort();
    Ok(out)
}

fn walk(root: &Path, rel: &Path, out: &mut Vec<PathBuf>) -> Result<()> {
    let dir = root.join(rel);
    for entry in fs::read_dir(&dir).map_err(io_err(&dir))? {
        let entry = entry.map_err(io_err(&dir))?;
        let name = entry.file_name();
        if is_ignored(&name.to_string_lossy()) {
            continue;
        }
        let file_type = entry.file_type().map_err(io_err(&dir))?;
        let child = rel.join(&name);
        if file_type.is_dir() {
            walk(root, &child, out)?;
        } else if file_type.is_file() {
            out.push(child);
        }
    }
    Ok(())
}

        bits_per_sample: fmt.bits,
        sample_format: if fmt.float { hound::SampleFormat::Float } else { hound::SampleFormat::Int },
    };
    let mut writer = hound::WavWriter::create(path, spec).unwrap();
    let max = ((1i64 << (fmt.bits - 1)) - 1) as f32;
    for i in 0..frames {
        let v = amplitude * (2.0 * std::f32::consts::PI * freq * i as f32 / fmt.sample_rate as f32).sin();
        for _ in 0..fmt.channels {
            if fmt.float {
                writer.write_sample(v).unwrap();
            } else {
                writer.write_sample((v * max).round() as i32).unwrap();
            }
        }
    }
    writer.finalize().unwrap();
}

/// Writes interleaved 16-bit samples as they are.
pub fn write_i16_wav(path: &Path, sample_rate: u32, channels: u16, samples: &[i16]) {
    let spec = hound::WavSpec { channels, sample_rate, bits_per_sample: 16, sample_format: hound::SampleFormat::Int };
    let mut writer = hound::WavWriter::create(path, spec).unwrap();
    for &s in samples {
        writer.write_sample(s).unwrap();
    }
    writer.finalize().unwrap();
}

    let mut reader = hound::WavReader::open(path).unwrap();
    let spec = reader.spec();
    let samples = reader.samples::<i16>().map(|s| s.unwrap()).collect();

}

/// `(chunk id, chunk size)` for every top-level chunk of a RIFF/WAVE file.
pub fn riff_chunks(path: &Path) -> Vec<(String, u32)> {
    let bytes = std::fs::read(path).unwrap();

        let size = u32::from_le_bytes(bytes[pos + 4..pos + 8].try_into().unwrap());

    }

//! Reads any supported audio file into planar f32 samples (symphonia).

use std::fs::File;
use std::path::Path;

use symphonia::core::audio::SampleBuffer;
use symphonia::core::codecs::{CodecParameters, DecoderOptions, CODEC_TYPE_NULL};
use symphonia::core::errors::Error as SymphoniaError;
use symphonia::core::formats::{FormatOptions, FormatReader};
use symphonia::core::io::MediaSourceStream;
use symphonia::core::meta::MetadataOptions;
use symphonia::core::probe::Hint;
use symphonia::core::sample::SampleFormat;

use crate::error::{io_err, CoreError, Result};

#[derive(Debug, Clone, PartialEq)]
pub struct AudioBuffer {
    pub channels: Vec<Vec<f32>>,
    pub sample_rate: u32,
}

impl AudioBuffer {
    pub fn frames(&self) -> usize {
        self.channels.first().map_or(0, Vec::len)
    }
}

#[derive(Debug, Clone, PartialEq)]
pub struct DecodedAudio {
    pub buffer: AudioBuffer,
    /// True when the source is integer PCM of 16 bits or less, so converting back to
    /// 16 bits without resampling loses nothing and needs no dither.
    pub exact_16bit: bool,
}

#[derive(Debug, Clone, PartialEq)]
pub struct AudioInfo {
    pub frames: Option<u64>,
    pub sample_rate: Option<u32>,
    pub channels: Option<usize>,
}

pub fn decode_file(path: &Path) -> Result<DecodedAudio> {
    let (mut format, track_id, params) = open(path)?;
    let mut decoder = symphonia::default::get_codecs()
        .make(&params, &DecoderOptions::default())
        .map_err(map_err)?;
    let mut sample_rate = params.sample_rate.unwrap_or(0);
    let mut channels: Vec<Vec<f32>> = vec![Vec::new(); params.channels.map_or(0, |c| c.count())];

    loop {
        let packet = match format.next_packet() {
            Ok(packet) => packet,
            Err(SymphoniaError::IoError(e)) if e.kind() == std::io::ErrorKind::UnexpectedEof => break,
            Err(SymphoniaError::ResetRequired) => break,
            Err(e) => return Err(map_err(e)),
        };
        if packet.track_id() != track_id {
            continue;
        }
        let decoded = match decoder.decode(&packet) {
            Ok(decoded) => decoded,
            Err(SymphoniaError::DecodeError(_)) => continue,
            Err(e) => return Err(map_err(e)),
        };
        let spec = *decoded.spec();
        let n_ch = spec.channels.count();
        if channels.len() != n_ch {
            if channels.iter().any(|c| !c.is_empty()) {
                return Err(CoreError::Decode("channel count changed mid-stream".into()));
            }
            channels = vec![Vec::new(); n_ch];
        }
        sample_rate = spec.rate;
        let mut samples = SampleBuffer::<f32>::new(decoded.capacity() as u64, spec);
        samples.copy_interleaved_ref(decoded);
        for (i, s) in samples.samples().iter().enumerate() {
            channels[i % n_ch].push(*s);
        }
    }

    if channels.is_empty() || sample_rate == 0 {
        return Err(CoreError::Decode("no audio channels found".into()));
    }
    let exact_16bit = matches!(params.bits_per_sample, Some(bits) if bits <= 16)
        && !matches!(params.sample_format, Some(SampleFormat::F32 | SampleFormat::F64));
    Ok(DecodedAudio { buffer: AudioBuffer { channels, sample_rate }, exact_16bit })
}

pub fn probe_info(path: &Path) -> Result<AudioInfo> {
    let (_, _, params) = open(path)?;
    Ok(AudioInfo {
        frames: params.n_frames,
        sample_rate: params.sample_rate,
        channels: params.channels.map(|c| c.count()),
    })
}

fn open(path: &Path) -> Result<(Box<dyn FormatReader>, u32, CodecParameters)> {
    let file = File::open(path).map_err(io_err(path))?;
    let stream = MediaSourceStream::new(Box::new(file), Default::default());
    let mut hint = Hint::new();
    if let Some(ext) = path.extension().and_then(|e| e.to_str()) {
        hint.with_extension(ext);
    }
    let probed = symphonia::default::get_probe()
        .format(&hint, stream, &FormatOptions::default(), &MetadataOptions::default())
        .map_err(map_err)?;
    let format = probed.format;
    let track = format
        .tracks()
        .iter()
        .find(|t| t.codec_params.codec != CODEC_TYPE_NULL)
        .ok_or_else(|| CoreError::Decode("no audio track".into()))?;
    let (track_id, params) = (track.id, track.codec_params.clone());
    Ok((format, track_id, params))
}

fn map_err(error: SymphoniaError) -> CoreError {
    match error {
        SymphoniaError::Unsupported(_) => CoreError::UnsupportedFormat,
        other => CoreError::Decode(other.to_string()),
    }
}

//! Turns decoded audio into SP-404 MKII samples: ≤2 channels, 48 kHz, 16-bit.

use rubato::{Resampler, SincFixedIn, SincInterpolationParameters, SincInterpolationType, WindowFunction};

use crate::decode::{AudioBuffer, DecodedAudio};
use crate::error::{CoreError, Result};

pub const TARGET_RATE: u32 = 48_000;
const RESAMPLE_CHUNK: usize = 1024;

#[derive(Debug, Clone, PartialEq)]
pub struct Quantized {
    pub interleaved: Vec<i16>,
    pub clipped_samples: u64,
}

#[derive(Debug, Clone, PartialEq)]
pub struct Processed {
    pub interleaved: Vec<i16>,
    pub channels: u16,
    pub clipped_samples: u64,
    pub downmixed_from: Option<usize>,
}

pub fn process(decoded: DecodedAudio, downmix_multichannel: bool) -> Result<Processed> {
    let DecodedAudio { buffer, exact_16bit } = decoded;
    let AudioBuffer { mut channels, sample_rate } = buffer;

    let mut downmixed_from = None;
    if channels.len() > 2 {
        if !downmix_multichannel {
            return Err(CoreError::TooManyChannels(channels.len()));
        }
        downmixed_from = Some(channels.len());
        channels = downmix_to_stereo(&channels);
    }

    let resampled = sample_rate != TARGET_RATE;
    if resampled {
        channels = resample(&channels, sample_rate, TARGET_RATE)?;
    }

    let dither = !(exact_16bit && !resampled && downmixed_from.is_none());
    let quantized = quantize(&channels, dither);
    Ok(Processed {
        interleaved: quantized.interleaved,
        channels: channels.len() as u16,
        clipped_samples: quantized.clipped_samples,
        downmixed_from,
    })
}

/// 6 channels are treated as standard 5.1 (FL, FR, FC, LFE, SL, SR): ITU weights, LFE
/// dropped, normalized so a full-scale signal cannot clip. Any other layout: even-indexed
/// channels are averaged into left, odd-indexed into right.
pub fn downmix_to_stereo(channels: &[Vec<f32>]) -> Vec<Vec<f32>> {
    let frames = channels.first().map_or(0, Vec::len);
    if channels.len() == 6 {
        let c = std::f32::consts::FRAC_1_SQRT_2;
        let norm = 1.0 / (1.0 + 2.0 * c);
        let (fl, fr, fc, sl, sr) = (&channels[0], &channels[1], &channels[2], &channels[4], &channels[5]);
        let left = (0..frames).map(|i| (fl[i] + c * fc[i] + c * sl[i]) * norm).collect();
        let right = (0..frames).map(|i| (fr[i] + c * fc[i] + c * sr[i]) * norm).collect();
        return vec![left, right];
    }
    let mut left = vec![0.0f32; frames];
    let mut right = vec![0.0f32; frames];
    let (mut n_left, mut n_right) = (0usize, 0usize);
    for (index, channel) in channels.iter().enumerate() {
        let target = if index % 2 == 0 {
            n_left += 1;
            &mut left
        } else {
            n_right += 1;
            &mut right
        };
        for (t, s) in target.iter_mut().zip(channel) {
            *t += s;
        }
    }
    for s in left.iter_mut() {
        *s /= n_left.max(1) as f32;
    }
    for s in right.iter_mut() {
        *s /= n_right.max(1) as f32;
    }
    vec![left, right]
}

pub fn resample(channels: &[Vec<f32>], from_rate: u32, to_rate: u32) -> Result<Vec<Vec<f32>>> {
    let n_channels = channels.len();
    let frames = channels.first().map_or(0, Vec::len);
    if frames == 0 || from_rate == to_rate {
        return Ok(channels.to_vec());
    }
    let ratio = to_rate as f64 / from_rate as f64;
    let params = SincInterpolationParameters {
        sinc_len: 256,
        f_cutoff: 0.95,
        interpolation: SincInterpolationType::Linear,
        oversampling_factor: 256,
        window: WindowFunction::BlackmanHarris2,
    };
    let mut resampler = SincFixedIn::<f32>::new(ratio, 1.0, params, RESAMPLE_CHUNK, n_channels)
        .map_err(|e| CoreError::Resample(e.to_string()))?;
    let delay = resampler.output_delay();
    let expected = (frames as f64 * ratio).round() as usize;
    let mut out: Vec<Vec<f32>> = vec![Vec::with_capacity(expected + delay + 2 * RESAMPLE_CHUNK); n_channels];

    let mut pos = 0;
    while frames - pos >= RESAMPLE_CHUNK {
        let block: Vec<&[f32]> = channels.iter().map(|c| &c[pos..pos + RESAMPLE_CHUNK]).collect();
        let produced = resampler.process(&block, None).map_err(|e| CoreError::Resample(e.to_string()))?;
        append(&mut out, produced);
        pos += RESAMPLE_CHUNK;
    }
    if pos < frames {
        let block: Vec<&[f32]> = channels.iter().map(|c| &c[pos..]).collect();
        let produced = resampler
            .process_partial(Some(block.as_slice()), None)
            .map_err(|e| CoreError::Resample(e.to_string()))?;
        append(&mut out, produced);
    }
    while out[0].len() < expected + delay {
        let produced = resampler
            .process_partial(None::<&[Vec<f32>]>, None)
            .map_err(|e| CoreError::Resample(e.to_string()))?;
        append(&mut out, produced);
    }
    for channel in out.iter_mut() {
        channel.drain(..delay);
        channel.truncate(expected);
    }
    Ok(out)
}

fn append(out: &mut [Vec<f32>], produced: Vec<Vec<f32>>) {
    for (dst, src) in out.iter_mut().zip(produced) {
        dst.extend(src);
    }
}

/// Scales to 16-bit, optionally adding TPDF dither (±1 LSB), and clamps.
/// `clipped_samples` counts samples beyond ±1.0 (above 0 dBFS) before quantizing.
pub fn quantize(channels: &[Vec<f32>], dither: bool) -> Quantized {
    let frames = channels.first().map_or(0, Vec::len);
    let mut rng = XorShift64(0x9E37_79B9_7F4A_7C15);
    let mut interleaved = Vec::with_capacity(frames * channels.len());
    let mut clipped_samples = 0u64;
    for i in 0..frames {
        for channel in channels {
            let x = channel[i];
            if x > 1.0 || x < -1.0 {
                clipped_samples += 1;
            }
            let mut v = x as f64 * 32768.0;
            if dither {
                v += rng.next_f64() - rng.next_f64();
            }
            interleaved.push(v.round().clamp(-32768.0, 32767.0) as i16);
        }
    }
    Quantized { interleaved, clipped_samples }
}

/// Small deterministic PRNG for dither (same input → same output file).
struct XorShift64(u64);

impl XorShift64 {
    fn next_u64(&mut self) -> u64 {
        let mut x = self.0;
        x ^= x << 13;
        x ^= x >> 7;
        x ^= x << 17;
        self.0 = x;
        x
    }

    /// Uniform in [0, 1).
    fn next_f64(&mut self) -> f64 {
        (self.next_u64() >> 11) as f64 / (1u64 << 53) as f64
    }
}

//! Writes output files atomically: data goes to `<name>.part`, then is renamed, so an
//! interrupted run never leaves a half-written file under the final name.

use std::ffi::OsString;
use std::fs;
use std::path::{Path, PathBuf};

use hound::{SampleFormat, WavSpec, WavWriter};

use crate::error::{io_err, CoreError, Result};
use crate::process::TARGET_RATE;

pub fn part_path(dest: &Path) -> PathBuf {
    let mut name: OsString = dest.as_os_str().to_owned();
    name.push(".part");
    PathBuf::from(name)
}

/// 16-bit / 48 kHz PCM. hound writes a plain 16-byte `fmt ` chunk for ≤2 channels at
/// 16 bits, and no metadata chunks.
pub fn write_wav(dest: &Path, channels: u16, interleaved: &[i16]) -> Result<()> {
    let part = part_path(dest);
    let spec = WavSpec { channels, sample_rate: TARGET_RATE, bits_per_sample: 16, sample_format: SampleFormat::Int };
    let written = (|| -> std::result::Result<(), hound::Error> {
        let mut writer = WavWriter::create(&part, spec)?;
        for &sample in interleaved {
            writer.write_sample(sample)?;
        }
        writer.finalize()
    })();
    if let Err(e) = written {
        let _ = fs::remove_file(&part);
        return Err(CoreError::Encode(e.to_string()));
    }
    fs::rename(&part, dest).map_err(io_err(dest))
}

pub fn copy_file(source: &Path, dest: &Path) -> Result<()> {
    let part = part_path(dest);
    if let Err(source_err) = fs::copy(source, &part) {
        let _ = fs::remove_file(&part);
        return Err(CoreError::Io { path: dest.to_path_buf(), source: source_err });
    }
    fs::rename(&part, dest).map_err(io_err(dest))
}

//! One file in, one SP-404 WAV out.

use std::path::Path;

use serde::Serialize;

use crate::config::Settings;
use crate::error::Result;
use crate::process::TARGET_RATE;
use crate::{decode, encode, process};

/// The SP-404 MKII's limit for a single sample.
pub const MAX_SAMPLE_SECONDS: f64 = 16.0 * 60.0;

#[derive(Debug, Clone, PartialEq, Serialize)]
#[serde(tag = "kind", rename_all = "camelCase")]
pub enum Warning {
    Clipped { samples: u64 },
    TooLong { seconds: f64 },
    Downmixed { channels: usize },
}

pub fn collect_warnings(frames: usize, clipped_samples: u64, downmixed_from: Option<usize>) -> Vec<Warning> {
    let mut warnings = Vec::new();
    if let Some(channels) = downmixed_from {
        warnings.push(Warning::Downmixed { channels });
    }
    if clipped_samples > 0 {
        warnings.push(Warning::Clipped { samples: clipped_samples });
    }
    let seconds = frames as f64 / TARGET_RATE as f64;
    if seconds > MAX_SAMPLE_SECONDS {
        warnings.push(Warning::TooLong { seconds });
    }
    warnings
}

pub fn convert_file(source: &Path, dest: &Path, settings: &Settings) -> Result<Vec<Warning>> {
    let decoded = decode::decode_file(source)?;
    let processed = process::process(decoded, settings.downmix_multichannel)?;
    let frames = processed.interleaved.len() / usize::from(processed.channels.max(1));
    let warnings = collect_warnings(frames, processed.clipped_samples, processed.downmixed_from);
    encode::write_wav(dest, processed.channels, &processed.interleaved)?;
    Ok(warnings)
}

//! if its size and modification time still match what was recorded.

use std::fs;
use std::path::{Path, PathBuf};
use std::time::SystemTime;

use serde::{Deserialize, Serialize};

use crate::config::app_data_dir;
use crate::error::{io_err, CoreError, Result};

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct ManifestEntry {
    pub path: PathBuf,
    pub size: u64,
    pub modified: SystemTime,
}

#[derive(Debug, Clone, Default, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct Manifest {
    pub files: Vec<ManifestEntry>,
    /// Folders the conversion created (they did not exist before).
    pub dirs: Vec<PathBuf>,
}

#[derive(Debug, Clone, Default, PartialEq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct UndoReport {
    pub removed: usize,
    pub kept_modified: Vec<PathBuf>,
    pub failed: Vec<PathBuf>,
    pub missing: usize,
    pub removed_dirs: usize,
}

impl Manifest {
    pub fn save_to(&self, path: &Path) -> Result<()> {
        if let Some(parent) = path.parent() {
            fs::create_dir_all(parent).map_err(io_err(parent))?;
        }
        let json = serde_json::to_string_pretty(self).map_err(|e| CoreError::Internal(e.to_string()))?;
        fs::write(path, json).map_err(io_err(path))
    }

    pub fn load_from(path: &Path) -> Result<Option<Manifest>> {
        if !path.exists() {
            return Ok(None);
        }
        let text = fs::read_to_string(path).map_err(io_err(path))?;
        serde_json::from_str(&text)
            .map(Some)
            .map_err(|e| CoreError::Internal(format!("corrupt undo manifest: {e}")))
    }
}

pub fn record(path: &Path) -> Option<ManifestEntry> {
    let meta = fs::metadata(path).ok()?;
    Some(ManifestEntry { path: path.to_path_buf(), size: meta.len(), modified: meta.modified().ok()? })
}

pub fn undo(manifest: &Manifest, remove_empty_dirs: bool) -> UndoReport {
    let mut report = UndoReport::default();
    for entry in &manifest.files {
        match fs::metadata(&entry.path) {
            Err(_) => report.missing += 1,
            Ok(meta) => {
                let unchanged = meta.len() == entry.size && meta.modified().ok() == Some(entry.modified);
                if !unchanged {
                    report.kept_modified.push(entry.path.clone());
                } else if fs::remove_file(&entry.path).is_ok() {
                    report.removed += 1;
                } else {
                    report.failed.push(entry.path.clone());
                }
            }
        }
    }
    if remove_empty_dirs {
        let mut dirs = manifest.dirs.clone();
        dirs.sort_by_key(|d| std::cmp::Reverse(d.components().count()));
        for dir in dirs {
            // remove_dir only succeeds on empty folders, so user files are never touched.
            if fs::remove_dir(&dir).is_ok() {
                report.removed_dirs += 1;
            }
        }
    }
    report
}

pub fn manifest_path() -> PathBuf {
    app_data_dir().join("last_session.json")
}

pub fn undo_last_session(manifest_file: &Path, remove_empty_dirs: bool) -> Result<Option<UndoReport>> {
    let Some(manifest) = Manifest::load_from(manifest_file)? else {
        return Ok(None);
    };
    let report = undo(&manifest, remove_empty_dirs);
    fs::remove_file(manifest_file).map_err(io_err(manifest_file))?;
    Ok(Some(report))
}

//! Executes a `Plan` in parallel, reporting progress and recording what it created.

use std::collections::BTreeSet;
use std::fs;
use std::path::PathBuf;
use std::sync::atomic::{AtomicBool, AtomicUsize, Ordering};

use rayon::prelude::*;
use serde::Serialize;

use crate::config::Settings;
use crate::convert::{convert_file, Warning};
use crate::encode::copy_file;
use crate::error::{io_err, CoreError, Result};
use crate::scan::{Job, JobKind, Plan};
use crate::undo::{self, Manifest};

pub const LOG_FILE_NAME: &str = "conversion_results.json";

#[derive(Debug, Clone, PartialEq, Serialize)]
#[serde(tag = "kind", rename_all = "camelCase")]
pub enum FileStatus {
    Converted,
    Copied,
    Skipped,
    Failed { reason: String },
    Cancelled,
}

#[derive(Debug, Clone, PartialEq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct FileResult {
    pub source: PathBuf,
    pub dest: PathBuf,
    pub status: FileStatus,
    pub warnings: Vec<Warning>,
}

#[derive(Debug, Clone, Default, PartialEq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct Summary {
    pub converted: usize,
    pub copied: usize,
    pub skipped: usize,
    pub failed: usize,
    pub cancelled: usize,
    pub with_warnings: usize,
    pub results: Vec<FileResult>,
}

impl Summary {
    pub fn from_results(results: Vec<FileResult>) -> Summary {
        let mut summary = Summary::default();
        for result in &results {
            match result.status {
                FileStatus::Converted => summary.converted += 1,
                FileStatus::Copied => summary.copied += 1,
                FileStatus::Skipped => summary.skipped += 1,
                FileStatus::Failed { .. } => summary.failed += 1,
                FileStatus::Cancelled => summary.cancelled += 1,
            }
            if !result.warnings.is_empty() {
                summary.with_warnings += 1;
            }
        }
        summary.results = results;
        summary
    }
}

#[derive(Debug, Clone, PartialEq, Serialize)]
#[serde(tag = "event", rename_all = "camelCase")]
pub enum Event {
    Started { total: usize },
    FileDone { done: usize, total: usize, result: FileResult },
    Finished { summary: Summary },
}

pub fn run<F>(plan: &Plan, settings: &Settings, cancel: &AtomicBool, on_event: F) -> Result<(Summary, Manifest)>
where
    F: Fn(Event) + Sync,
{
    let jobs: Vec<&Job> = plan.jobs().collect();
    let total = jobs.len();
    on_event(Event::Started { total });

    let created_dirs = if cancel.load(Ordering::SeqCst) { Vec::new() } else { create_output_dirs(plan)? };
    let pool = rayon::ThreadPoolBuilder::new()
        .num_threads(settings.workers.max(1))
        .build()
        .map_err(|e| CoreError::Internal(e.to_string()))?;
    let done = AtomicUsize::new(0);
    let results: Vec<FileResult> = pool.install(|| {
        jobs.par_iter()
            .map(|job| {
                let result = run_job(job, settings, cancel);
                let done_now = done.fetch_add(1, Ordering::SeqCst) + 1;
                on_event(Event::FileDone { done: done_now, total, result: result.clone() });
                result
            })
            .collect()
    });

    let mut manifest = Manifest {
        files: results
            .iter()
            .filter(|r| matches!(r.status, FileStatus::Converted | FileStatus::Copied))
            .filter_map(|r| undo::record(&r.dest))
            .collect(),
        dirs: created_dirs,
    };

    if settings.write_json_log {
        for pack in &plan.packs {
            if !pack.dest_root.is_dir() {
                continue;
            }
            let pack_results: Vec<&FileResult> =
                results.iter().filter(|r| r.dest.starts_with(&pack.dest_root)).collect();
            let log_path = pack.dest_root.join(LOG_FILE_NAME);
            let json = serde_json::to_string_pretty(&pack_results).map_err(|e| CoreError::Internal(e.to_string()))?;
            fs::write(&log_path, json).map_err(io_err(&log_path))?;
            if let Some(entry) = undo::record(&log_path) {
                manifest.files.push(entry);
            }
        }
    }

    let summary = Summary::from_results(results);
    on_event(Event::Finished { summary: summary.clone() });
    Ok((summary, manifest))
}

fn run_job(job: &Job, settings: &Settings, cancel: &AtomicBool) -> FileResult {
    let mut warnings = Vec::new();
    let status = if cancel.load(Ordering::SeqCst) {
        FileStatus::Cancelled
    } else if job.kind == JobKind::Unsupported {
        FileStatus::Failed { reason: CoreError::UnsupportedFormat.to_string() }
    } else if job.dest.exists() {
        FileStatus::Skipped
    } else if job.kind == JobKind::Convert {
        match convert_file(&job.source, &job.dest, settings) {
            Ok(found) => {
                warnings = found;
                FileStatus::Converted
            }
            Err(e) => FileStatus::Failed { reason: e.to_string() },
        }
    } else {
        match copy_file(&job.source, &job.dest) {
            Ok(()) => FileStatus::Copied,
            Err(e) => FileStatus::Failed { reason: e.to_string() },
        }
    };
    FileResult { source: job.source.clone(), dest: job.dest.clone(), status, warnings }
}

/// Creates every missing output folder up front and returns the ones it created,
/// deepest first (the order undo needs).
fn create_output_dirs(plan: &Plan) -> Result<Vec<PathBuf>> {
    let mut missing = BTreeSet::new();
    for job in plan.jobs().filter(|j| j.kind != JobKind::Unsupported) {
        let mut dir = job.dest.parent();
        while let Some(d) = dir {
            if d.as_os_str().is_empty() || d.exists() {
                break;
            }
            missing.insert(d.to_path_buf());
            dir = d.parent();
        }
    }
    let mut dirs: Vec<PathBuf> = missing.into_iter().collect();
    dirs.sort_by_key(|d| d.components().count());
    for dir in &dirs {
        fs::create_dir_all(dir).map_err(io_err(dir))?;
    }
    dirs.reverse();
    Ok(dirs)
}

//! Rough free-space check before converting. Conservative on purpose.

use std::fs;
use std::path::{Path, PathBuf};

use crate::decode::{probe_info, AudioInfo};
use crate::error::{io_err, CoreError, Result};
use crate::process::TARGET_RATE;
use crate::scan::{JobKind, Plan};

const WAV_HEADER_BYTES: u64 = 44;
/// Used when the header does not tell the length (e.g. some MP3s): a 128 kbps MP3
/// grows about 12× as 16-bit / 48 kHz stereo WAV.
const UNKNOWN_LENGTH_GROWTH: u64 = 12;

pub fn estimate_output_bytes(plan: &Plan) -> u64 {
    plan.jobs()
        .filter(|job| !job.already_exists)
        .map(|job| match job.kind {
            JobKind::Convert => estimate_wav_bytes(&job.source),
            JobKind::Copy => fs::metadata(&job.source).map(|m| m.len()).unwrap_or(0),
            JobKind::Unsupported => 0,
        })
        .sum()
}

fn estimate_wav_bytes(source: &Path) -> u64 {
    match probe_info(source) {
        Ok(AudioInfo { frames: Some(frames), sample_rate: Some(rate), channels: Some(channels) }) if rate > 0 => {
            let out_frames = (frames as f64 * TARGET_RATE as f64 / rate as f64).ceil() as u64;
            WAV_HEADER_BYTES + out_frames * channels.min(2) as u64 * 2
        }
        _ => fs::metadata(source)
            .map(|m| m.len().saturating_mul(UNKNOWN_LENGTH_GROWTH))
            .unwrap_or(0),
    }
}

pub fn ensure_space(needed: u64, available: u64) -> Result<()> {
    if needed > available {
        return Err(CoreError::InsufficientSpace { needed, available });
    }
    Ok(())
}

/// Every pack's destination volume must fit the whole batch (simple and conservative).
pub fn check_free_space(plan: &Plan) -> Result<()> {
    let needed = estimate_output_bytes(plan);
    for pack in &plan.packs {
        let probe_dir = existing_ancestor(&pack.dest_root);
        let available = fs4::available_space(&probe_dir).map_err(io_err(&probe_dir))?;
        ensure_space(needed, available)?;
    }
    Ok(())
}

fn existing_ancestor(path: &Path) -> PathBuf {
    let mut current = path;
    while !current.exists() {
        match current.parent() {
            Some(parent) => current = parent,
            None => break,
        }
    }
    current.to_path_buf()
}

```rust
use std::path::{Path, PathBuf};
use std::process::ExitCode;
use std::sync::atomic::AtomicBool;

use clap::{Parser, Subcommand};
use sp404_core::config::{SaveMode, Settings};
use sp404_core::runner::{self, Event, FileStatus};
use sp404_core::scan::{self, JobKind, Plan};
use sp404_core::{space, undo};

#[derive(Parser)]
#[command(name = "sp404", version, about = "Convert sample packs to Roland SP-404 MKII format (16-bit / 48 kHz WAV)")]
struct Cli {
    #[command(subcommand)]
    command: Command,
}

#[derive(Subcommand)]
enum Command {
    /// Convert one or more pack folders
    Convert {
        #[arg(required = true)]
        packs: Vec<PathBuf>,
        /// Output folder (otherwise the saved settings decide)
        #[arg(long)]
        out: Option<PathBuf>,
        /// Show what would happen without writing anything
        #[arg(long)]
        dry_run: bool,
        /// Write conversion_results.json into each output pack
        #[arg(long)]
        json_log: bool,
    },
    /// Delete the files created by the last conversion
    Undo {
        /// Also remove folders left empty
        #[arg(long)]
        remove_empty_dirs: bool,
    },
}

fn main() -> ExitCode {
    let cli = Cli::parse();
    let outcome = match cli.command {
        Command::Convert { packs, out, dry_run, json_log } => convert(&packs, out.as_deref(), dry_run, json_log),
        Command::Undo { remove_empty_dirs } => undo_last(remove_empty_dirs),
    };
    match outcome {
        Ok(code) => code,
        Err(message) => {
            eprintln!("error: {message}");
            ExitCode::FAILURE
        }
    }
}

fn convert(packs: &[PathBuf], out: Option<&Path>, dry_run: bool, json_log: bool) -> Result<ExitCode, String> {
    let mut settings = Settings::load();
    if out.is_some() {
        settings.save_mode = SaveMode::Ask;
    }
    if json_log {
        settings.write_json_log = true;
    }
    let plan = scan::build_plan(packs, out, &settings).map_err(|e| e.to_string())?;
    if dry_run {
        print_plan(&plan);
        return Ok(ExitCode::SUCCESS);
    }
    space::check_free_space(&plan).map_err(|e| e.to_string())?;
    let cancel = AtomicBool::new(false);
    let (summary, manifest) = runner::run(&plan, &settings, &cancel, |event| {
        if let Event::FileDone { done, total, result } = event {
            let label = match &result.status {
                FileStatus::Converted => String::from("converted"),
                FileStatus::Copied => String::from("copied"),
                FileStatus::Skipped => String::from("skipped (already exists)"),
                FileStatus::Failed { reason } => format!("FAILED: {reason}"),
                FileStatus::Cancelled => String::from("cancelled"),
            };
            println!("[{done}/{total}] {} — {label}", result.source.display());
        }
    })
    .map_err(|e| e.to_string())?;
    manifest.save_to(&undo::manifest_path()).map_err(|e| e.to_string())?;
    println!(
        "\n{} converted, {} copied, {} skipped, {} failed, {} with warnings",
        summary.converted, summary.copied, summary.skipped, summary.failed, summary.with_warnings
    );
    Ok(if summary.failed > 0 { ExitCode::from(1) } else { ExitCode::SUCCESS })
}

fn print_plan(plan: &Plan) {
    for pack in &plan.packs {
        println!("{} -> {}", pack.source_root.display(), pack.dest_root.display());
        for job in &pack.jobs {
            let source = job.source.strip_prefix(&pack.source_root).unwrap_or(&job.source);
            let dest = job.dest.strip_prefix(&pack.dest_root).unwrap_or(&job.dest);
            let kind = match job.kind {
                JobKind::Convert => "convert",
                JobKind::Copy => "copy",
                JobKind::Unsupported => "unsupported",
            };
            let note = if job.already_exists { "  (exists, will skip)" } else { "" };
            println!("  {kind:<11} {} -> {}{note}", source.display(), dest.display());
        }
    }
}

fn undo_last(remove_empty_dirs: bool) -> Result<ExitCode, String> {
    match undo::undo_last_session(&undo::manifest_path(), remove_empty_dirs).map_err(|e| e.to_string())? {
        None => println!("Nothing to undo."),
        Some(report) => {
            println!("Removed {} files and {} folders.", report.removed, report.removed_dirs);
            for path in &report.kept_modified {
                println!("Kept (changed since the conversion): {}", path.display());
            }
            for path in &report.failed {
                println!("Could not remove: {}", path.display());
            }
        }
    }
    Ok(ExitCode::SUCCESS)
}

```python
"""Writes app-icon.png (1024x1024): a dark rounded square with a 4x4 pad grid."""
import struct
import sys
import zlib

SIZE = 1024
MARGIN, RADIUS = 64, 180
BODY, PAD, ACCENT = (29, 29, 31, 255), (72, 72, 76, 255), (255, 106, 19, 255)
GRID_START, CELL, GAP = 200, 140, 28


def inside_rounded(x, y):
    lo, hi = MARGIN, SIZE - MARGIN
    if not (lo <= x < hi and lo <= y < hi):
        return False
    cx = min(max(x, lo + RADIUS), hi - RADIUS)
    cy = min(max(y, lo + RADIUS), hi - RADIUS)
    return (x - cx) ** 2 + (y - cy) ** 2 <= RADIUS ** 2


def pixel(x, y):
    if not inside_rounded(x, y):
        return (0, 0, 0, 0)
    gx, gy = x - GRID_START, y - GRID_START
    if 0 <= gx < 4 * (CELL + GAP) and 0 <= gy < 4 * (CELL + GAP):
        col, row = gx // (CELL + GAP), gy // (CELL + GAP)
        if gx % (CELL + GAP) < CELL and gy % (CELL + GAP) < CELL:
            return ACCENT if (col, row) == (0, 3) else PAD
    return BODY


def chunk(kind, data):
    return struct.pack(">I", len(data)) + kind + data + struct.pack(">I", zlib.crc32(kind + data) & 0xFFFFFFFF)


rows = bytearray()
for y in range(SIZE):
    rows.append(0)
    for x in range(SIZE):
        rows.extend(pixel(x, y))
png = (
    b"\x89PNG\r\n\x1a\n"
    + chunk(b"IHDR", struct.pack(">IIBBBBB", SIZE, SIZE, 8, 6, 0, 0, 0))
    + chunk(b"IDAT", zlib.compress(bytes(rows), 9))
    + chunk(b"IEND", b"")
)
with open(sys.argv[1] if len(sys.argv) > 1 else "app-icon.png", "wb") as f:
    f.write(png)
```

import { getCurrentWebview } from "@tauri-apps/api/webview";
import { ask, open } from "@tauri-apps/plugin-dialog";
import * as api from "./api";
import type { FileResult, PackSummary, Plan, SaveMode, Settings, Summary, Warning } from "./api";
import { applyI18n, t } from "./i18n";

const byId = <T extends HTMLElement>(id: string) => document.getElementById(id) as T;

const dropZone = byId<HTMLElement>("drop-zone");
const packList = byId<HTMLUListElement>("pack-list");
const output = byId<HTMLElement>("output");
const progressSection = byId<HTMLElement>("progress");
const progressBar = byId<HTMLProgressElement>("progress-bar");
const progressLabel = byId<HTMLElement>("progress-label");
const convertBtn = byId<HTMLButtonElement>("convert-btn");
const dryRunBtn = byId<HTMLButtonElement>("dry-run-btn");
const undoBtn = byId<HTMLButtonElement>("undo-btn");
const clearBtn = byId<HTMLButtonElement>("clear-btn");
const browseBtn = byId<HTMLButtonElement>("browse-btn");
const cancelBtn = byId<HTMLButtonElement>("cancel-btn");
const settingsBtn = byId<HTMLButtonElement>("settings-btn");
const settingsDialog = byId<HTMLDialogElement>("settings-dialog");
const settingsForm = byId<HTMLFormElement>("settings-form");
const chooseFixedBtn = byId<HTMLButtonElement>("choose-fixed-btn");
const fixedDirLabel = byId<HTMLElement>("fixed-dir-label");

let packs: PackSummary[] = [];
let settings: Settings;
let busy = false;

function el<K extends keyof HTMLElementTagNameMap>(tag: K, text?: string, className?: string): HTMLElementTagNameMap[K] {
  const node = document.createElement(tag);
  if (text !== undefined) node.textContent = text;
  if (className) node.className = className;
  return node;
}

const fileName = (path: string) => path.split(/[\\/]/).pop() ?? path;
const relative = (path: string, root: string) =>
  path.startsWith(root) ? path.slice(root.length).replace(/^[\\/]/, "") : path;

function refreshButtons() {
  const empty = packs.length === 0;
  convertBtn.disabled = busy || empty;
  dryRunBtn.disabled = busy || empty;
  clearBtn.disabled = busy || empty;
  browseBtn.disabled = busy;
  settingsBtn.disabled = busy;
}

async function refreshUndo() {
  undoBtn.disabled = busy || !(await api.hasUndo());
}

function setBusy(value: boolean) {
  busy = value;
  progressSection.hidden = !value;
  undoBtn.disabled = value;
  refreshButtons();
}

function showMessage(text: string, kind: "info" | "error" = "info") {
  output.replaceChildren(el("p", text, kind));
}

function renderPacks() {
  packList.replaceChildren(
    ...packs.map((pack) => {
      const item = el("li");
      const remove = el("button", "×", "icon");
      remove.title = t("remove");
      remove.addEventListener("click", () => {
        packs = packs.filter((p) => p.path !== pack.path);
        renderPacks();
      });
      item.append(
        el("strong", pack.name),
        el("span", t("packFiles", { audio: pack.audioFiles, other: pack.otherFiles, unsupported: pack.unsupportedFiles }), "muted"),
        remove,
      );
      return item;
    }),
  );
  dropZone.classList.toggle("compact", packs.length > 0);
  refreshButtons();
}

async function addPaths(paths: string[]) {
  const fresh = paths.filter((p) => !packs.some((pack) => pack.path === p));
  if (fresh.length === 0 || busy) return;
  try {
    packs = packs.concat(await api.inspectPacks(fresh));
    renderPacks();
    output.replaceChildren();
  } catch (error) {
    showMessage(String(error), "error");
  }
}

async function browse() {
  if (busy) return;
  const picked = await open({ directory: true, multiple: true, title: t("browse") });
  if (picked) await addPaths(Array.isArray(picked) ? picked : [picked]);
}

async function buildPlan(): Promise<Plan | undefined> {
  let outputDir: string | null = null;
  if (settings.saveMode === "ask") {
    const picked = await open({ directory: true, multiple: false, title: t("chooseOutput") });
    if (typeof picked !== "string") return undefined;
    outputDir = picked;
  }
  return api.planConversion(packs.map((p) => p.path), outputDir);
}

function renderPlan(plan: Plan) {
  const nodes: HTMLElement[] = [el("h2", t("dryRunTitle"))];
  for (const pack of plan.packs) {
    nodes.push(el("h3", `${pack.name} → ${pack.destRoot}`));
    const list = el("ul", undefined, "file-list");
    for (const job of pack.jobs) {
      const note = job.kind === "unsupported" ? ` — ${t("unsupported")}` : job.alreadyExists ? ` — ${t("willSkip")}` : "";
      const cls = job.kind === "unsupported" ? "error" : job.alreadyExists ? "muted" : undefined;
      list.append(el("li", `${relative(job.source, pack.sourceRoot)} → ${relative(job.dest, pack.destRoot)}${note}`, cls));
    }
    nodes.push(list);
  }
  output.replaceChildren(...nodes);
}

async function dryRun() {
  if (busy || packs.length === 0) return;
  try {
    const plan = await buildPlan();
    if (plan) renderPlan(plan);
  } catch (error) {
    showMessage(String(error), "error");
  }
}

function setProgress(done: number, total: number) {
  progressBar.max = Math.max(total, 1);
  progressBar.value = done;
  progressLabel.textContent = t("progress", { done, total });
}

function describeWarning(warning: Warning): string {
  switch (warning.kind) {
    case "clipped":
      return t("warnClipped", { samples: warning.samples });
    case "tooLong":
      return t("warnTooLong", { minutes: (warning.seconds / 60).toFixed(1) });
    case "downmixed":
      return t("warnDownmixed", { channels: warning.channels });
  }
}

function describeResult(result: FileResult): HTMLElement | undefined {
  const parts: string[] = [];
  if (result.status.kind === "failed") parts.push(result.status.reason);
  parts.push(...result.warnings.map(describeWarning));
  if (parts.length === 0) return undefined;
  return el("li", `${fileName(result.source)} — ${parts.join("; ")}`, result.status.kind === "failed" ? "error" : "warning");
}

function renderSummary(summary: Summary) {
  const nodes: HTMLElement[] = [
    el("h2", t("summaryTitle")),
    el(
      "p",
      t("summaryCounts", {
        converted: summary.converted,
        copied: summary.copied,
        skipped: summary.skipped,
        failed: summary.failed,
        cancelled: summary.cancelled,
        warnings: summary.withWarnings,
      }),
    ),
  ];
  const problems = summary.results.map(describeResult).filter((item): item is HTMLElement => item !== undefined);
  if (problems.length > 0) {
    const list = el("ul", undefined, "file-list");
    list.append(...problems);
    nodes.push(list);
  }
  output.replaceChildren(...nodes);
}

async function convertAll() {
  if (busy || packs.length === 0) return;
  let plan: Plan | undefined;
  try {
    plan = await buildPlan();
  } catch (error) {
    showMessage(String(error), "error");
    return;
  }
  if (!plan) return;
  setBusy(true);
  setProgress(0, 0);
  output.replaceChildren();
  try {
    const summary = await api.convert(plan, (event) => {
      if (event.event === "started") setProgress(0, event.total);
      else if (event.event === "fileDone") setProgress(event.done, event.total);
    });
    renderSummary(summary);
  } catch (error) {
    showMessage(String(error), "error");
  } finally {
    setBusy(false);
    await refreshUndo();
  }
}

async function undoLast() {
  if (busy) return;
  if (!(await ask(t("undoConfirm"), { title: t("undo"), kind: "warning" }))) return;
  const removeEmptyDirs = await ask(t("undoRemoveDirs"), { title: t("undo") });
  try {
    const report = await api.undoLast(removeEmptyDirs);
    showMessage(
      report
        ? t("undoDone", { removed: report.removed, dirs: report.removedDirs, kept: report.keptModified.length + report.failed.length })
        : t("nothingToUndo"),
    );
  } catch (error) {
    showMessage(String(error), "error");
  }
  await refreshUndo();
}

const BOOLEAN_SETTINGS = ["sanitizeFilenames", "sanitizeFolderNames", "flattenFolders", "downmixMultichannel", "writeJsonLog"] as const;

function field<T extends HTMLInputElement | HTMLSelectElement>(name: string): T {
  return settingsForm.elements.namedItem(name) as T;
}

function fillSettingsForm() {
  for (const key of BOOLEAN_SETTINGS) field<HTMLInputElement>(key).checked = settings[key];
  field<HTMLInputElement>("maxFilenameLength").value = settings.maxFilenameLength?.toString() ?? "";
  field<HTMLSelectElement>("saveMode").value = settings.saveMode;
  field<HTMLInputElement>("workers").value = String(settings.workers);
  fixedDirLabel.textContent = settings.fixedDirectory ?? t("notSet");
}

function readSettingsForm(): Settings {
  const maxLength = parseInt(field<HTMLInputElement>("maxFilenameLength").value, 10);
  const workers = parseInt(field<HTMLInputElement>("workers").value, 10);
  const next: Settings = {
    ...settings,
    maxFilenameLength: Number.isFinite(maxLength) && maxLength > 0 ? maxLength : null,
    saveMode: field<HTMLSelectElement>("saveMode").value as SaveMode,
    workers: Number.isFinite(workers) && workers > 0 ? Math.min(workers, 32) : 1,
  };
  for (const key of BOOLEAN_SETTINGS) next[key] = field<HTMLInputElement>(key).checked;
  return next;
}

async function persistSettings() {
  try {
    await api.saveSettings(settings);
  } catch (error) {
    showMessage(String(error), "error");
  }
}

function openSettings() {
  if (busy) return;
  fillSettingsForm();
  settingsDialog.showModal();
}

async function init() {
  applyI18n();
  settings = await api.getSettings();
  renderPacks();
  await refreshUndo();

  browseBtn.addEventListener("click", () => void browse());
  dryRunBtn.addEventListener("click", () => void dryRun());
  convertBtn.addEventListener("click", () => void convertAll());
  undoBtn.addEventListener("click", () => void undoLast());
  cancelBtn.addEventListener("click", () => void api.cancelConversion());
  clearBtn.addEventListener("click", () => {
    packs = [];
    renderPacks();
    output.replaceChildren();
  });
  settingsBtn.addEventListener("click", openSettings);
  settingsForm.addEventListener("change", () => {
    settings = readSettingsForm();
    void persistSettings();
  });
  chooseFixedBtn.addEventListener("click", async () => {
    const picked = await open({ directory: true, multiple: false, title: t("sFixed") });
    if (typeof picked !== "string") return;
    settings = { ...readSettingsForm(), fixedDirectory: picked, saveMode: "fixed" };
    fillSettingsForm();
    await persistSettings();
  });

  window.addEventListener("keydown", (event) => {
    if (!(event.metaKey || event.ctrlKey)) return;
    if (event.key.toLowerCase() === "o") {
      event.preventDefault();
      void browse();
    } else if (event.key === "Enter") {
      event.preventDefault();
      void convertAll();
    } else if (event.key === ",") {
      event.preventDefault();
      openSettings();
    }
  });

  await getCurrentWebview().onDragDropEvent((event) => {
    const payload = event.payload;
    if (payload.type === "enter" || payload.type === "over") {
      dropZone.classList.add("hover");
    } else if (payload.type === "leave") {
      dropZone.classList.remove("hover");
    } else if (payload.type === "drop") {
      dropZone.classList.remove("hover");
      void addPaths(payload.paths);
    }
  });
}

void init();

```markdown
# SP-404 MKII Converter

Converte sample packs inteiros para o formato nativo da Roland SP-404 MKII:
WAV 16 bits / 48 kHz, nomes limpos, estrutura de pastas preservada.
Funciona no macOS e no Windows.

## O que ele faz

- Lê WAV, AIFF, FLAC, MP3, M4A/AAC, OGG Vorbis e CAF (qualquer taxa e resolução).
- Converte para 48 kHz com resampler sinc de alta qualidade e reduz para 16 bits com dither TPDF.
  Arquivos que já estão em 16 bits / 48 kHz saem idênticos.
- Mono continua mono, estéreo continua estéreo; arquivos com mais canais são mixados para estéreo.
- Remove metadados, limpa nomes (ASCII), resolve nomes repetidos (`kick_2.wav`).
- Copia capas, PDFs e textos junto. Ignora lixo do sistema (`.DS_Store`, `__MACOSX`, `._arquivo`).
- Dry Run, Desfazer a última conversão, pular arquivos já convertidos, log JSON opcional.

## Usar

1. Abra o app e arraste as pastas dos packs para a janela (ou ⌘/Ctrl+O).
2. Clique em **Converter tudo** (⌘/Ctrl+Enter) e escolha onde salvar.
3. Copie a pasta gerada para o cartão SD e importe na SP-404 MKII.

Configurações: ⌘/Ctrl+, ou o botão ⚙.

# Publicando uma versão

## Versão sem assinatura (atual)

1. Atualize `version` em `Cargo.toml` (workspace), `app/package.json` e `app/src-tauri/tauri.conf.json`.
2. Commit, depois `git tag v0.1.0 && git push --tags`.
3. O workflow **Release** gera um rascunho de release no GitHub com:
   - `SP-404 MKII Converter_<versão>_aarch64.dmg` (Mac Apple Silicon)
   - `SP-404 MKII Converter_<versão>_x64.dmg` (Mac Intel)
   - `SP-404 MKII Converter_<versão>_x64-setup.exe` (Windows, instala sem administrador)
4. Revise e publique o rascunho.

Sem assinatura, o macOS mostra "desenvolvedor não identificado" (abrir com clique direito → Abrir)
e o Windows mostra o aviso do SmartScreen ("Mais informações" → "Executar assim mesmo").

## Antes de distribuir publicamente

- **Assinatura e notarização Apple:** conta Apple Developer; configure os secrets
  `APPLE_CERTIFICATE`, `APPLE_CERTIFICATE_PASSWORD`, `APPLE_SIGNING_IDENTITY`, `APPLE_ID`,
  `APPLE_PASSWORD` e `APPLE_TEAM_ID` no repositório — o `tauri-action` usa automaticamente.
- **Assinatura Windows:** certificado de code signing; configure `bundle.windows.certificateThumbprint`
  (ou assinatura via Azure Trusted Signing) em `tauri.conf.json`.
- **Atualização automática:** adicione `tauri-plugin-updater`, gere as chaves com
  `npx tauri signer generate`, coloque a chave pública e o endpoint em `plugins.updater`
  no `tauri.conf.json`, mude `bundle.createUpdaterArtifacts` para `true` e configure os secrets
  `TAURI_SIGNING_PRIVATE_KEY` / `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`.
- **Nome:** "SP-404" é marca da Roland. Para distribuição pública, considere um nome próprio
  (ex.: "… for SP-404 MKII") e um aviso de que o app não é afiliado à Roland.
